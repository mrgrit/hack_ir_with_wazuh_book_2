# 2권 전체 분석 보강 산출물 계약

- 요청: 6장의 Wazuh 분석을 보강하고 다른 장도 전체 점검하여 다시 작성한다.
- 대상: 1~13장과 부록, 별도 DOCX 14개. 합본·배포 PDF·REV01 제외.
- 기준: 기존 원고의 실습 범위와 Module 01 원전. 실제 조회와 원전 관찰, 미확인 결과를 구분한다.
- 기본 문서: `tools/assets/bookk-B5.docx`. 188×263mm, 기존 여백·테마·서체를 유지한다.
- 편집 원칙: 검색 이후의 동일 사건 연결, 실제 결과 해석, 대응 결정과 종결 조건을 장별 사례로 완성한다. 이미 충분한 절차는 보존하고 중복 일반론은 늘리지 않는다.
- 증거: 기존 실습 기록과 2026-11-04 집필 작업의 읽기 조회. 증거 내부 시각은 조회 시각과 별도 기록한다. 새 공격·보호 해제·로그 삭제·합성 적재는 수행하지 않는다.
- 재생성: `tools/revise_analysis.py`에서 기존 생성기에 적용할 보강을 관리한다. 예제와 본문 입력을 일치시킨다.
- 검수: 전체 본문·표·명령·검색식·캡션·참고 URL 점검, DOCX 렌더 및 페이지별 육안 검사. 이전 승인 페이지와 픽셀상 같은 페이지는 대응 관계를 기록한다.
- 완료: 장별 DOCX·JSON·복사용 예제·저자 검토 기록을 커밋하고 지정 집필 저장소에 push, 원격 HEAD 대조.
