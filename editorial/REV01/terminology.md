# REV01 표기와 판단 기준

| 대상 | 표기·구분 |
|---|---|
| 인쇄 지면 | 쪽. 화면의 페이지·페이지 크기 등 제품 기능 이름은 해당 문맥을 따른다. |
| 파일 경로 | 설명은 디렉터리. 실제 UI의 Folder 등 고유 표기는 유지한다. |
| 주소 | 출발지 IP·목적지 IP. 필드는 data.srcip·data.src_ip 등 실제 이름을 보존한다. |
| HTTP | HTTP 상태 코드. 단순 성공 여부와 본문·이동 주소·후속 효과를 구분한다. |
| 검색 언어 | Discover의 DQL, Dev Tools의 JSON DSL, osquery의 SQL을 구분한다. |
| 원상복구 | 실습 전 상태로 되돌리는 절차에 사용한다. 일반 데이터 복구와 구분한다. |
| 실행 위치 | kt66 VM · 터미널, Windows PC · PowerShell, Windows 실습 게스트 · 관리자 PowerShell, 이름 있는 컨테이너로 구분한다. |
| 번호 | EventID=이벤트 종류, EventRecordID=해당 컴퓨터·채널의 기록 번호, rule.id=Wazuh 분석 규칙. |
| 프로세스 | Sysmon ProcessGuid와 PID를 구분한다. System ProcessID는 이벤트 공급자별 의미를 확인한다. |
| 경보·이벤트 | 수집 이벤트, 경보 규칙 일치, 공격 시도, 공격 성공, 대응 효과를 따로 기록한다. |
| 현재 상태·이력 | Vulnerability/SCA/osquery의 조회 시각과 이벤트 생성 시각을 구분한다. |
| 수치 | 전체 건수·반환 건수·고유 객체 수, 분모·기간·시간대·누락·중복을 명시한다. |
| UI | 고유 메뉴·버튼 표기는 제품 화면을 따른다. 강조가 필요한 신규 안내는 굵게 표시한다. 경로와 입력 문자열에 임의 기호를 추가하지 않는다. |
| 본문 참조 | 쪽의 상대 위치보다 장·절·명령 번호를 사용한다. |
| 인용 | 장말은 R번호·자료명·읽을 이유, 참고문헌은 자료명과 전체 URL을 제공한다. |

기록되지 않은 값은 채워 넣지 않는다. 관찰 사실 → 가능한 설명 → 필요한 후속 증거 → 판단·종결 기준 순서로 설명한다. 기법명·경보 제목·규칙 이름은 공격 성공의 대체 증거로 사용하지 않는다.
