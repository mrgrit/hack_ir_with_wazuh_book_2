# 12장 집필·검토 기록

2026-11-03. 「장기 로그의 피벗과 집계」, 25쪽. Module 01 645~704쪽. 공통 출처와 검증 한계는 [전체 기록](remaining-review.md)을 따른다.

## 원전과 현재 자료

원전의 합성 45,199문서·217 IP와 실제 조회 결과를 구분한다. 현재 synthetic.flag:true는 0건이다. 생성 코드는 고정 kt66의 analytics/kt66_synth.py를 읽었으며 생성·적재·삭제는 하지 않았다. 소스의 직접 인덱서 적재는 Wazuh 관리자 디코딩·규칙 판정을 통과한 실증이 아니다. 현재 자료가 없으면 원전 결과와 가정값 계산표를 사용한다.

## 해석·명령 교정

- srcip와 src_ip의 OR 전체를 괄호로 묶고 synthetic 조건을 AND로 적용한다. IP 없는 FIM·명령·권한 기록을 별도 계정·호스트 피벗으로 보존한다.
- 낮은 레벨의 31100 등 문서가 있으므로 전체 건수와 레벨 5 이상 건수의 모집단을 분리한다. 센서 수와 대상 시스템 수, 관측 기간과 활동 일수를 구분한다.
- terms 기본 10건, size 증가의 한계, sum_other_doc_count와 오차, cardinality 근삿값, hits.total.relation gte의 하한 의미를 설명한다.
- 집계 전 field_caps의 실제 자료형을 확인한다. 최종 D12-01은 URL fields=*이며 현재 서버에서 성공했다. JSON 본문의 fields 배열 시도는 400으로 폐기했다.
- D12-03·04는 한 요청을 나눈 조각이다. 완성본 ip-profile.http를 제공하고 단독 실행하지 않도록 앞뒤 설명을 둔다. DQL과 Dev Tools 기간이 자동 동기화된다고 쓰지 않는다.
- 업무외는 Asia/Seoul 주말 또는 평일 09시 이전·18시 이후다. 지정 휴일은 별도 달력이 필요하다. 분모·분자·0 분모·정수 나눗셈을 설명한다.
- 간격 10·10·10·100초의 평균 32.5, 모집단 표준편차 약 38.97, 버스트성 약 0.0905를 계산 연습으로 제공한다. 주기성·악성 의도의 증명으로 사용하지 않는다.
- source --delete는 넓은 합성 문서 범위를 지울 수 있어 일반 원상복구 명령으로 제공하지 않았다. 생성 파일의 경로·존재 사전 확인과 사후 건수·해시 확인을 연결한다.

## 검증

셸 3개는 구문만 검사했다. DQL 12개는 모두 구문 수용·현재 0건을 확인했다. 최종 field_caps, count/범위, IP profile, 업무외 집계 GET을 확인했다. 현재 문서로 합성 조건을 제외한 별도 읽기 확인에서는 전체 17,610건, 업무외 10,459건, 비율 0.593923906871096이었다. 이는 원전 합성 결과가 아니다.
