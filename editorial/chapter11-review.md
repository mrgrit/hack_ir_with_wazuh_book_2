# 11장 집필·검토 기록

2026-11-03. 「네트워크 경보와 일일 관제」, 18쪽. 실습 59~61, Module 01 602~626쪽. 공통 출처와 검증 한계는 [전체 기록](remaining-review.md)을 따른다.

## 해석 교정

- Suricata 6.0.4의 현재 명령줄은 eth2·eth0 캡처와 autofp 실행이다. 컨테이너 이름 ips를 인라인 차단의 증거로 사용하지 않는다. local.rules의 alert, EVE, Wazuh 수집·규칙, 별도 nft 경로를 나누어 설명한다.
- Suricata severity는 작은 값이 더 높은 중요도, Wazuh rule.level은 큰 값이 높은 심각도다. action allowed는 안전이나 공격 성공 판정이 아니다. 200 응답도 침해 성공을, 403도 특정 보안장비의 차단을 단독으로 증명하지 않는다.
- Suricata 주소 필드는 src_ip·dest_ip다. 일반 srcip와 구분하고 시각·주소·포트·URL을 웹·호스트 기록과 연결한다. 원전 signature와 action 값의 양성 화면을 현재 빈 검색과 섞지 않는다.
- MITRE 전술·기법은 관측 행위를 분류하는 태그이며 순차 공격 단계·전체 커버리지·공격자 귀속을 입증하지 않는다. 태그 누락과 낮은 레벨의 선행·후속 기록을 별도로 찾는다.
- 일일 검토는 수집 상태→후보→전후 기록→영향→담당자·기한→재확인 순서다. 저장 검색과 예약 실행·통지 기능을 구분한다.

## 검증과 삽화 교정

명령 5개 구문과 현재 프로세스·설정·EVE·수집·규칙을 확인했다. DQL 9개 결과는 0·0·0·0·69·126·13·7·438건이다. 새로운 스캔·공격 트래픽·차단을 만들지 않았다. 실제 0건의 Suricata 검색을 양성 탐지 검증으로 쓰지 않는다.

현재 UI 세 장과 원전 608·609쪽 화면 두 장, 도식 두 장, 사무실 삽화 한 장을 사용했다. 최초 생성 그림의 몸통과 다리가 서로 다른 방향을 향한다는 사용자 지적에 따라, 의자에 앉아 평평한 문서에 기록하는 옆 3/4 구도로 고쳤다. 선택본 `exec-77c4545f-49b7-4fc3-a824-774bb93ff08f.png`의 골반·허벅지·무릎·발 연결과 의자 지지를 원본·지면에서 확인했다. 거절본 `exec-5977c51d-30f3-43fa-93a8-e468aa284d5e.png`는 포함하지 않았다.
